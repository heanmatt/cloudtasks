Step-by-Step Deployment Guide (Port 8081 App & Port 8080 Jenkins)

Copy and paste these exact commands to push to GitHub, set up AWS EC2, and deploy with Jenkins.

Step 1: Push Project to GitHub

cd cloudtasks
git init -b main
git add .
git commit -m "feat: CloudTasks Pro v2.1 on port 8081 with Jenkins CI/CD"
git remote add origin https://github.com/heanmatt/cloudtasks.git
git push -u origin main --force

Step 2: AWS EC2 Security Group Inbound Ports

In AWS Console → EC2 → Security Groups → Edit Inbound Rules, allow TCP from 0.0.0.0/0 on:

Port 22   (SSH Terminal)
Port 8081 (Main CloudTasks Pro Web App via Nginx Reverse Proxy)
Port 3000 (Direct Web Frontend Container)
Port 4000 (Direct Node.js REST API Health & JSON)
Port 8080 (Jenkins CI/CD Server)

Step 3: Install Docker & Jenkins on EC2 (or Deploy Immediately)

ssh -i your-key.pem ubuntu@<EC2_PUBLIC_IP>
git clone https://github.com/heanmatt/cloudtasks.git
cd cloudtasks
chmod +x scripts/ec2-setup.sh scripts/verify.sh
sudo ./scripts/ec2-setup.sh

Step 4: Configure Jenkins Pipeline on Port 8080

1. Open http://<EC2_PUBLIC_IP>:8080
2. New Item -> Name: cloudtasks-deploy -> Pipeline -> OK
3. Build Triggers: Poll SCM (H/2 * * * *) or GitHub hook trigger
4. Pipeline: Pipeline script from SCM -> Git -> https://github.com/heanmatt/cloudtasks.git
5. Branch: */main -> Script Path: Jenkinsfile -> Save -> Build Now!
